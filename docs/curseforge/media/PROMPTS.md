# Image generation prompts

Generated with the built-in image_gen tool for Music Reforged by hash014.
The logo is an original transparent project mark. The banner is promotional
illustration; administration gallery images are real screenshots.

## Logo

```text
Use case: logo-brand.
Asset type: original square project avatar and reusable logo mark for "Music Reforged", a Minecraft server music plugin by hash014.
Primary request: create one polished, distinctive logo, centered on a truly transparent square 1024 by 1024 canvas. It must read immediately at small icon sizes.
Subject: an original geometric jukebox/audio cube emblem with a bold musical note integrated into its front face; the note and cube should form one coherent recognizable symbol.
Style: crisp vector-like 2D brand illustration, blocky angular construction inspired by voxel geometry, restrained two-tone facets, very clean silhouettes and carefully balanced negative space. Not a screenshot or a game asset texture.
Palette: deep navy blue #24485f, warm copper-orange #dd8b26, ivory #f1eee6, one small pale-blue accent. These match the plugin's existing administration UI.
Composition: one large centered emblem occupying roughly 75 percent of the canvas; generous clear margins. Strong navy outer silhouette, copper front panel, ivory musical note. Keep the composition visually balanced and the outline unambiguous.
Text: none. No letters or watermark. No Minecraft, Mojang or CurseForge logos. No copied game textures, no generic game logo, no scenery. Output only the single logo with genuine alpha transparency.
```

## Banner

```text
Use case: ads-marketing.
Asset type: polished wide description banner for the CurseForge page of Music Reforged, a Minecraft server music plugin by hash014.
Input image 1 is the project's original logo reference: preserve its recognizable jukebox cube, navy/copper/ivory palette and musical-note motif. This is a new banner, not an edit of the logo file.
Canvas: panoramic landscape approximately 1920 by 640, 3:1 aspect ratio. A complete self-contained banner with generous margins; no frame or mockup.
Style: art-directed illustrated branding, crisp original voxel landscape forms, warm copper highlights against deep navy twilight. Clean and restrained, high readability, with a rich but uncluttered background. No copied Minecraft textures or official game logos.
Composition: place the logo emblem on the right third, slightly above an original block-built stone pedestal. Behind it, understated blocky trees and terrain suggest a world whose ambience changes with location. Subtle flowing amber sound arcs tie the landscape together. Keep the left two-thirds calm and dark enough for the title.
Text, verbatim, exactly these three strings: "MUSIC REFORGED" as the large dominant title; "Your world. Your soundtrack." as a smaller subheading; "made by hash014" as a modest signature. Make the title strong, angular and carefully spaced, in ivory with restrained copper accents, without imitating the Minecraft wordmark. All text must be fully readable, correctly spelled and inside safe margins.
Constraints: no extra text, no feature claims about version coverage, no watermarks, no CurseForge logo, no characters, no simulated game HUD. Promotional illustration, not a gameplay screenshot.
```
